# Design Tokens

## Naming convention

We use a structured naming system:

- `--color-*`  Primitive colors (raw values from Figma)
- `--background-*`  Background and surface colors
- `--text-*`  Text colors
- `--icon-*` Icon colors
- `--button-*` Button styles

## Example

- `--color-primary-700`  Base brand color
- `--button-primary-bg`  Background color for primary button
- `--text-default`  Default text color

## Notes

- All tokens are based on Figma variables
- Semantic tokens reference primitive tokens
- This makes it easy to update the design system globally
