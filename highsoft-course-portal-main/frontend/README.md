# Frontend – Highsoft Course Portal

This folder contains the frontend for the Highsoft Course Portal, developed as part of the First Year Industry Project.

## Structure

- `index.html` – landing page
- `course-detail.html` – course overview page
- `lesson.html` – lesson/content page
- `certificates.html` – certificates/completion page

- `css/` – styling, variables, components and layout
- `js/` – frontend JavaScript and interactions
- `images/` – logos, illustrations and other assets
- `design-system/` – design system documentation, tokens and component notes
- `docs/` – project notes and additional documentation

## Current status

- Frontend folder structure has been set up
- HTML pages are connected to CSS files
- Design tokens and semantic variables from Figma have been added to CSS
- Base component styling has been started for buttons, inputs, tags, cards, header and progress bar
