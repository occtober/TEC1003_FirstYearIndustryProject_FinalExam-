Good to Know Before You Start

System Requirements

Highcharts is based on native browser technologies. To ensure your setup can run Highcharts smoothly, please make sure your browser is compatible as per the requirements: https://www.highcharts.com/docs/getting-started/system-requirements

Optional Dependencies

Although Highcharts is self-contained by default, there are some external third-party libraries required to enable certain features. These features are linked to client-side exporting and support for latitude/longitude in Highcharts Maps. For more details, see https://www.highcharts.com/docs/getting-started/optional-dependencies.

Source Available

Highcharts is source-available software, which means you can view and test the source code (like we are doing in this course), but it is not the same as open source software. The key distinction is that open source software is generally free to use, even for commercial purposes, while source available software like Highcharts comes with specific restrictions, such as requiring a paid license for commercial use. In the case of Highcharts, there are paid commercial licenses, but also free licenses for personal use and educational purposes. Read more at https://www.highcharts.com/blog/education/ and https://shop.highcharts.com/.

What is Highcharts?

Highcharts is a charting library that makes it easy for developers to create interactive data visualizations in web projects.

  • Browser-based: Highcharts is built in JavaScript and works natively in browser environments without extra dependencies.
  • Client-side: Highcharts runs entirely in the browser, making it portable and easy to integrate into existing projects. This also means Highcharts is backend-agnostic, so it can fetch and visualize data from any server setup or data source.
  • Lightweight and modular: With a small footprint and minimal dependencies, Highcharts remains efficient. Additionally, its modular design lets you include only what you need.
  • SVG-based graphics: Highcharts uses SVG (Scalable Vector Graphics). This means chart elements are real DOM nodes that can be styled and animated with CSS or JavaScript, scaled without losing quality, and accessed by other web technologies. Compared to canvas-based rendering, this provides clearer structure, better rendering, and integration with the DOM.

Key Features

Highcharts is flexible as well as easy to use. Beginners can quickly get a chart up and running, while advanced users can dive deeper. Here are some of the key features:

  • Responsiveness: Charts automatically adapt to the size of their container, and reflow when the browser window is resized. You can also add your own responsiveness rules to modify chart design and layout across varying screen sizes.
  • Interactivity: Charts are interactive by default. Hovering over a data point shows its value in a tooltip, and the corresponding series highlights dynamically.
  • Smart defaults: Highcharts provides sensible defaults for colors, labels, and layout, so even a minimal configuration produces a clean and professional-looking chart.
  • Flexible styling: Charts can be styled through JavaScript options or via CSS in styled mode.
  • Data handling: Highcharts supports dynamic and asynchronous updates, making it possible to stream data or refresh charts in real time without reloading the page. It also handles large datasets efficiently with features like boosting.
  • Advanced customization: Highcharts can be extended and customized far beyond the built-in options, including the ability to add new features, create custom elements, or change how core parts of the library work.

Key Accessibility Features

Highcharts includes extensive accessibility features to make charts accessible to people with disabilities:

  • Screen reader support: Chart content is available to screen readers and assistive technologies via SVG and exported ARIA markup.
  • Keyboard navigation: Charts can be navigated and interacted with using the keyboard.
  • Accessibility-specific chart options: Developers can configure description text, series labels, or custom keyboard navigation.
  • Low vision features: Highcharts supports high contrast mode and pattern fills to improve readability for users with low vision or color blindness.
  • Sonification (audible charts): Charts can be turned into sound using pitch, volume, or timbre to represent data variables.

Additional Advantages

  • Broad browser support: Highcharts is tested across many browsers in their latest version.
  • Mobile friendly: Charts adapt well to mobile devices with touch support and high-DPI rendering.
  • Export options: Charts can be exported to PNG, JPEG, PDF, and SVG. Data can also be exported to CSV, XLS, and HTML tables.
  • Official framework integrations: Highcharts offers official integrations with React, Vue, and Angular.
  • Strong documentation and active community: Highcharts has an intuitive API, backed by extensive documentation and an active community.

Altogether, the Highcharts suite offers developers a professional, flexible, and accessible way to bring data to life on the web.

The Highcharts Product Suite

In this course, we will be working with Highcharts Core. But the Highcharts suite consists of several other libraries, each tailored for specific needs:

  • Highcharts Core: The core charting library, supporting line, bar, column, pie, and many more chart types.
  • Highcharts Stock: Extends Highcharts Core with additional features for timeline navigation and finance.
  • Highcharts Maps: Enables geospatial visualizations, choropleths, and interactive maps.
  • Highcharts Gantt: For project planning and scheduling with tasks, dependencies, and timelines.
  • Highcharts Dashboards: Combines charts, KPIs, tables, and other components into unified interactive dashboards.
  • Highcharts Grid: A spreadsheet-like data table, available as Grid Lite (free) and Grid Pro (advanced features).
